# Demo photos for Lapor reports

Every Lapor report needs a photo, so each demo problem has one. `npm run db:seed` stores these photos in the
database and gives each demo problem its own. If a file is added or changed later, running the seed again
replaces that photo. A problem without a file here shows a plain grey picture until its file is added.

## How to add a photo

1. Use your own photo, or one with a free licence that needs no credit. Each row below has a search on Pexels
   (everything there is free) and on Unsplash (filtered to free photos; skip any marked Unsplash+).
   Note the photo's page address in the **Source** column.
2. Choose a landscape photo that clearly shows the problem. Leave out faces, car plates and house numbers.
3. Save it in `scripts/demo-photos/incoming/` named with its file name, for example `pothole-deep.jpg` (any of
   .jpg, .jpeg, .png or .webp). That folder is not committed. The developer (Claude) then resizes each one to
   1280 px, saves it as JPEG without its hidden data (such as the GPS location) and puts it in this folder.

A Malaysian street scene suits the demo best: monsoon drains, a covered walkway, terrace houses or a guardhouse.
